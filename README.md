# Ça roule

Französische Zeitformen üben (Oberstufe, A1–B1): présent, passé composé, imparfait, futur composé, futur simple, impératif, conditionnel.
Acht Übungsarten, Deutsch/Französisch, Akzent-Knöpfe, Regelübersicht und Verbliste. Ohne Login, läuft komplett im Browser.

Live: https://novarion-desk.github.io/caroule/

## Arbeitsblatt
Auf dem Einstellungsbildschirm erstellt «🖨 Arbeitsblatt» aus den gewählten Zeitformen, Übungsarten, Satzarten und der Anzahl (∞ = 20) ein A4-Blatt mit Name/Datum und Schreibplatz. Erst Vorschau, dann Drucken / PDF; «Neu mischen» erzeugt ein anderes Blatt. Das Lösungsblatt ist immer dabei.

## Feedback
Der Knopf «💬 Feedback» öffnet ein externes, anonymes Formular bei Tally (Fehler, Wünsche, Inhalte). Nur dann werden Angaben gesendet – zusammen mit App-Name, Version und Gerätetyp. Namen werden nicht abgefragt.
